# Developer Profile

This Python terminal program is designed to allow the user to input their name and goals for learning Python.

## Features

- Asks for name and learning goal
- Blank name defaults to "Developer"
- Blank goal defaults to "Explore what I can build with Python."
- Removes surrounding whitespace and uses defaults for answers containing only spaces

## How to Run

You need Python 3 installed.

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

4. Answer the questions, or press Enter to use the defaults.
